## [0.1.0] - 2026-08-21

### Added

- Initial public release.

### Features

- synchronous HTTP/HTTPS GET
- synchronous HTTP/HTTPS POST
- HTTP request and response headers
- HTTP redirects
- chunked transfer encoding
- native TLS on Windows, macOS and optional on Linux
- rustls on Linux
- optional embedded CA certificate list
- no asynchronous runtime
